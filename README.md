# MedFlow Toolkit · Ferramentas de gestão hospitalar / Herramientas de gestión hospitalaria

**PT:** Ferramentas HTML (rodam inteiras no navegador) para operação hospitalar: estado de conta, orçamento cirúrgico, supply (estoque + ordens de compra), forecast de P&L extrato de pagamentos a médicos e reporte diário (Sala de Guerra). Todos os dados são fictícios e as demos já abrem preenchidas.

**ES:** Herramientas HTML (corren completas en el navegador) para la operación hospitalaria: estado de cuenta, presupuesto quirúrgico, supply (inventario + órdenes de compra), forecast de P&L y extracto de pagos a médicos y reporte diario (Sala de Guerra). Todos los datos son ficticios y las demos abren ya cargadas.
